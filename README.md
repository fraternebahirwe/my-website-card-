# 🎴 Developer Profile & Link Card

> A clean, responsive single-page profile card and micro-portfolio showcasing personal bio details, skill badges, quick contact/social links, and key project highlights.

---

## ✨ Key Components

- **Profile Hero Card:** Displays portrait, name, current role, location, and technical skill badges (`HTML`, `CSS`, `JavaScript`).
- **Quick Links Navigation:** Direct social and contact action links (`LinkedIn`, `GitHub`, and direct `mailto:` email).
- **About Section:** Concise personal bio and frontend background summary.
- **Featured Projects Grid:** 
  - ⚡ **Speed Typing Game** (Demo & GitHub links)
  - 📂 **Personal Portfolio** (GitHub repository link)
  - 🌍 **Open Source Contribution** (Pull Request link)
- **Footer:** Clean copyright tag.

---

## 🛠️ Built With

- **HTML5:** Semantic architecture (`<main>`, `<section>`, `<article>`, `<address>`, `<nav>`).
- **CSS3:** Custom layout styling (`styles.css`).
